Verify your download

Download the checksum into the same folder as the ISO. On Linux, run:

sha256sum -c kindred-os-0.5.2-amd64.iso.sha256

Check that the result says OK. For other systems, compare the SHA-256 value using your usual checksum tool.

Before you begin

  • Back up the files you want to keep.
  • Use a USB drive large enough for the installer.
  • Have Internet access during installation.
  • Turn off Secure Boot. Hardware support varies.

Installation can erase the disk you choose. Ask someone you trust to help if you’re unsure.

ALREADY AT HOME?

Keep your Kindred.
Bring it up to date.

Application updates preserve your Kindred documents, calendar notes and preferences. They do not repartition your computer or replace its bootloader.

One-time upgrade for 0.5.1 and earlier

The download source has moved to a public repository. An administrator needs to upgrade once before your older updater can accept that source.

Download application update ↗Download its checksum ↗
  1. Download both files into the same folder.
  2. Verify the checksum, then extract into a temporary folder.
  3. From that folder, run the administrator upgrade script:
sha256sum -c kindred-update-0.5.2.tar.gz.sha256
mkdir kindred-upgrade
tar xzf kindred-update-0.5.2.tar.gz -C kindred-upgrade
cd kindred-upgrade
sudo bash scripts/upgrade-existing.sh

The script keeps a backup and installs missing required app and media packages. Your work stays open. Sign in again when ready.

After this upgrade

Use Settings → Check for updates. Turn on Automatic Kindred updates for daily checks. Updates verify downloads, keep a previous installation backup, and don’t restart your session. Debian security and kernel maintenance are separate.
