A fresh start, with care.

Installation risks, online assistance and software licenses to review before downloading.

1. Installation and backup acknowledgment

Writing the installer image erases the USB drive. Installing Kindred can erase the computer disk you select, including its files and existing operating system. Back up the files you want to keep to a separate device or trusted service, and confirm that the backup opens. Check each disk choice before confirming.

Use a computer you own or have permission to change. Hardware support varies. Read the installation guide, including Internet and Secure Boot requirements. Ask someone you trust for help if you are unsure. The download checkbox acknowledges these risks; it is not a waiver of rights that the law protects.

2. Updates and security

Application updates are designed to preserve Kindred documents and settings, but you should still keep backups. They do not replace separate Debian security and kernel maintenance. Verify download checksums before installing. HTTPS and SHA-256 checks help protect downloads; the current update metadata is not digitally signed. Compatibility and interruption risks remain.

3. Online AI and other services

The assistant can make mistakes, including confident mistakes. Check important answers and actions. It is not a medical professional, financial adviser, lawyer or emergency service. For emergencies, contact your local emergency services.

Online answers are optional and send messages and recent conversation to the configured provider. The released Linux download uses NVIDIA and local voice recognition. Development Mac/Windows builds also offer cloud voice through OpenRouter. See the privacy policy. Other apps and websites require their own accounts, subscriptions and agreements where applicable. Kindred does not endorse or control their content.

4. Third-party licenses and source

Kindred is an independent Debian-based project. Debian packages and other bundled components retain their own copyrights and licenses. Their licenses control your rights to use, copy, modify and redistribute them; our website terms do not add restrictions to those rights.

For installed Debian packages, inspect the copyright and license files under /usr/share/doc/<package>/copyright. Debian’s package directory links to package details and source packages. With source repositories configured, apt source <package> retrieves Debian package source. These upstream sources do not by themselves establish that all source for a modified distributed component has been supplied.

For a source or license question about a specific Kindred download, identify the release and component in the website issue tracker. The public website repository contains website files and release downloads; it is not a complete source repository for the OS. This page does not grant a new license to Kindred-authored code or replace any obligation to supply corresponding source under a bundled component’s license.
